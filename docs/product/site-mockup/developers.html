For developers

Bring your own agent. Bring your own harness.

MCP-native, works with any harness. One command connects an agent, a local signer holds the only key, the budget is enforced on-chain.

Quickstart

Three steps to a paying agent.

01
Create an account and an agent
One passkey prompt, then an agent with a budget. It hands back the connector command.
02
Run the connector
It installs the MCP runtime and generates the signing key locally. Approve the budget with your passkey.
03
Verify, then pay
Call haven_get_agent. When spend_authority_readiness reads ready, the agent can pay.
# from the setup prompt your dashboard hands you $ npx -y @haven_ai/connect@<channel> \ --setup hv_setup_… --api <api-url> \ --ack-local-tools # the connector writes owner-only files, never to the repo ~/.haven/agents/<agent-id>/identity.json # API key: identifies, cannot spend ~/.haven/agents/<agent-id>/signer.json # signing key: never leaves the machine # verify from your agent haven_get_agent → spend_authority_readiness: ready
Architecture

Keyless where it is hosted. Keyed where it runs.

Three parts, and no single one of them can spend.

agent runtime

Local signer

Any harness. Holds the key and signs exactly what Haven prepared.

→
hosted MCP

Haven tools

Quote, prepare and relay. Never holds funds or a key.

→
on-chain

The owner's account

The budget is a signed delegation. Over budget reverts at execution.

Paying a 402

Quote, sign, pay.

Three tool calls settle a paywall. Every payment returns a receipt: agent, item, policy, proof. An interrupted payment can be resumed, never paid twice.

# An agent hits a paywall GET https://api.example/v1/enrich ← 402 Payment Required · 0.30 USDC haven_quote_x402 → within budget · 214.00 used of 250.00 haven_sign_x402 → signed on the agent's machine haven_pay_x402 → settled on Base · receipt issued ← 200 OK
Packages

Five packages on npm.

PackageWhat it isUse it when
@haven_ai/connectOne-command local connector. Installs the MCP runtime, generates the signing key locally.Connecting any agent. Start here.
@haven_ai/sdkTypeScript SDK: payments, x402 quote, pay and resume, allowances, receipts.You are integrating Haven into your own code.
@haven_ai/mcpLocal MCP server for credential-file integrations.Your runtime cannot reach the hosted MCP.
@haven_ai/signerLocal edge signer. The delegate key never leaves the machine.Installed by connect; run standalone if you split hosts.
@haven_ai/cliTerminal-native management: login, agents, budgets, funding.Scripting setup, or letting an agent manage the account.
# the CLI never signs: it prints a link, the owner signs with a passkey $ npx @haven_ai/cli@<channel> login $ haven agents connect --name research --budget 250 --token USDC --period 43200 $ haven budget grant <agentId> --amount 500 --token USDC --period 43200 --wait $ haven wallets funding
