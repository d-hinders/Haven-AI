Protocols

Two protocols. One budget. Same receipt.

Haven sits on the buy side of both: it lets your agent pay within a budget. x402 is live. Stripe's MPP is next.

The flow

One payment, four actors.

A price is named, Haven checks it against the budget, the agent signs locally, Haven relays, the chain enforces, the merchant delivers.

Side by side

What each protocol is, and what changes for you.

x402 · live

Pay-per-request over HTTP

An open standard under the Linux Foundation. A server answers with 402 and a price; the client pays and retries with proof. Any standard x402 merchant works with Haven today.

Stripe MPP · next

Agent-initiated commerce

Stripe's Machine Payments Protocol covers purchases an agent and a merchant coordinate: subscriptions, orders, checkout. Stablecoins first, fiat later.
