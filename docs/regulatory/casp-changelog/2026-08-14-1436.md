- **#1436** — an unenforced UI promise becomes an enforced backend invariant. Revoking an agent flips only `agents.status`; it never touches `agent_delegations`. Archiving (#1401) required only `status='revoked'`. So revoke→archive through the API — no dashboard, no revoke-all — filed an agent under "Removed" while its budget delegation stayed `active` and redeemable on-chain by whoever held the delegate key, and the agent list (which derives delegation-rail allowances without filtering on status or `archived_at`) rendered it under Removed **with its budget rows intact**, under copy that promises the agent has stopped spending. The #1402 Remove dialog always killed budgets first and the card hid the standalone Revoke for delegation agents, so this was unreachable from the dashboard — but a safety property that lives only in frontend orchestration is not enforced, and the endpoints in question are documented first-class API. `ARCHIVE_AGENT_SQL` now additionally requires `NOT EXISTS (pending|active row in agent_delegations)`, in the same statement (no check-then-act window), and the route distinguishes the two 409s so a caller is told the remedy that actually applies (`revoke-all` for live budgets, "revoke first" for a live credential). Authority analysis: this only ever REFUSES a state change — nothing new is permitted, no signature is bypassed, no on-chain call is made, and archiving remains a filing action that grants and revokes nothing. Legacy AllowanceModule agents hold no rows in this table, so the guard passes for them and their teardown remains the on-chain revoke path (documented at the constant). Crash-window orphans from #1423 (disabled on-chain, still `active` in the DB) correctly block archiving, and revoke-all — the remedy the refusal names — is exactly what heals them. Mutation-proven on the real-Postgres harness: replacing the NOT EXISTS with `TRUE` fails three tests that assert a revoked agent holding a pending/active delegation cannot be archived. Also fixed: the revoke-all pre-read refusal cited the batch cap (25) while gating on the reconcile ceiling (100), telling an agent with 150 delegations "150 > 25" — correct refusal, wrong number. Perimeter unchanged; one bypass of a stated product guarantee closed.
