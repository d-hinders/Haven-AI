# 2026-08-21 — #1682: name-first runtime picker in the connect modal

The dashboard's "Where will this agent run?" picker became a flat list of
product names (#1682), replacing #1672's collapsed "AI agent (Claude Code,
Codex, Cowork)" row: Claude Code (default), Claude Desktop, Codex, Cowork,
Cursor, Hermes Agent, OpenClaw, VS Code, "Not listed / other". Whether a row
produces the setup command or a config snippet is now a property of the row
rather than a question put to the user. Supporting changes: OpenClaw gains an
`mcpServers` snippet for `~/.openclaw/openclaw.json`, VS Code Insiders folds
into the VS Code row (its id stays accepted), the backend's command-path id
sets gain `codex`/`cowork`, the connector gains `cowork` and `openclaw`
aliases (the OpenClaw row needs that connect release on npm before it works
end to end).

Authority and custody are untouched. This moves **labels, id plumbing, and
which MCP config file the user is told to edit** — never what may be signed or
spent. The delegate key is still generated locally and never leaves the
machine, Haven still receives only the public address plus proof, budgets and
on-chain caveats are unmodified, and the connector's `openclaw` alias resolves
to a profile (`other`) that writes NO runtime config at all, so it cannot cause
a config to be written anywhere unintended. No payment, settlement, approval, or
sweep surface changes. Perimeter unchanged — the same argument as
[2026-08-21-1672.md](2026-08-21-1672.md).
