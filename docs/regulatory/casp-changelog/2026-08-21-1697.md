- **#1697** — `--doctor` becomes a per-agent inventory: it enumerates every credential directory on the machine, classifies each as wired/superseded/retired/orphaned, runs the full check set for every WIRED agent, exits non-zero if any of them fails any check, and adds an `identity_match` check comparing the agent the stored API key authenticates as against that directory's `signer.json` `delegate_address`. **No custody or authority boundary moves.** Everything here is diagnosis: the doctor remains read-only, its one new network call is an authenticated GET of the agent's own identity (`/machine-payments/agent`), it writes nothing, revokes nothing, and deletes nothing — the standing "connect reports, the user decides" rule (#1688) is unchanged, as is the rule that connect never overwrites credentials. Two things move in the safe direction. First, `identity_match` makes mechanical a check that on 2026-08-21 could only be performed by hand, mid-purchase: whether the API key a runtime authenticates with and the signing key it signs with belong to the **same** agent. A mismatch is the local, on-disk shadow of the hazard #1690 refuses at signing time, and it now fails the doctor with both identities named. Its limits are stated rather than glossed: it proves the on-disk pair is self-consistent, and cannot see inside an already-running host — that half remains covered by #1681's tombstone diagnosis and the restart guidance. Second, the "newest wins" heuristic is retired: it named one directory real and demoted every other to a note, which under multi-agent (#1696) would either hide a broken live agent or defame a legitimate one. Classification is now evidence-based (which signer wrapper the config actually launches; the unique entry name for a named pair), and where no evidence exists — a CLI-managed runtime whose config this module cannot read — the doctor degrades to the old heuristic explicitly rather than fabricating a verdict. Addresses are abbreviated in output and no API key or private key reaches either output form, asserted by test. Perimeter unchanged.
