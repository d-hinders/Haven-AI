# 2026-08-22 — #1719: the connector resolves its own runtime, with a real failure vocabulary

Connect's runtime-selection ladder (#1672) gained two rungs before its refusal
(#1719): an agent may **self-report** its harness — entering at the same
precedence as `--runtime`, so it can only ever fill a vacuum and still loses to
a confident environment detection — and a human at an interactive terminal is
offered the agent clients actually **installed** on that machine. The scan only
ever populates the choices; nothing selects for the user, and no scan result
resolves a runtime without an answer typed at the prompt. Every new way this
step can fail now carries a stable `errorCode` and a next action
(`runtime_undetermined`, `runtime_unrecognized`, `runtime_force_unrecognized`,
`runtime_no_installed_clients`, `runtime_prompt_aborted`,
`runtime_config_unreadable`) instead of a raw exception string.

Authority and custody are untouched: which MCP **config file** gets written is
what moves, never what may be signed or spent. The delegate key is still
generated locally and never leaves the machine, Haven still receives only the
public address plus proof, and budgets and on-chain caveats are unmodified. The
adjacent security property is strengthened rather than relaxed — a wrong
resolution would write an API key and a delegate key into a client the user does
not use, so the connector still refuses instead of guessing: an unrecognised
runtime name with nothing detected refuses outright, and the installed-client
scan never auto-selects (both asserted by tests). Every new refusal keeps the
#1161 ordering — it happens before `resolveSetup`, before a key is minted, and
before any credential write, so it cannot strand a half-created agent or burn a
setup token (mutation-proof tests assert nothing was written on each new path).
The one new failure that can occur after credentials exist, an unparseable
client config, is detected before the write and leaves the file byte-identical.
No payment, settlement, or sweep surface changes. Perimeter unchanged.
