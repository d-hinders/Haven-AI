- **#2258** — The dashboard no longer creates, manages, budgets, or revokes agents through the legacy Safe / AllowanceModule rail. Legacy accounts remain readable: balances, activity, transaction history, agent identity, and unlink/archive state remain available, and identity editing only updates the historical name and description. Haven no longer mediates revocation of an existing legacy AllowanceModule allowance; the Safe owner must handle any remaining permission outside Haven when owner access supports that path. The accepted consequence is that Haven's old transaction-builder path is gone and historical allowances were not cleared; the bounded exposure recorded in #1985 was 12 delegates and $0.02. Passkey-only or unknown-owner cases receive no promise of a self-serve Safe interface. This is separate from the live delegation rail's owner-signed `disableDelegation` exit path in [`docs/exit/README.md`](../../exit/README.md), which is unchanged. Perimeter narrowed.
