  **The one real risk is supply-chain, and it is treated as an execution
  surface rather than a label.** This constant decides which npm package a user
  is told to execute. `resolveConnectorChannel` therefore validates against
  `/^[a-z][a-z0-9-]{0,31}$/`, which is a shell boundary and not merely a
  tidiness check: the resulting spec is interpolated into an `npx <spec> …`
  command line that a human pastes into a real terminal. The pattern cannot
  express a different package, a registry, a path or any shell metacharacter, so
  a compromised value selects another Haven channel and nothing else. The
  excluded metacharacters are enumerated INDIVIDUALLY — one assertion per
  character, in the `excludes every shell metacharacter` case of
  `packages/sdk/src/connector-channel.test.ts` — rather than asserted as
  "rejects bad input", so a widened pattern fails on the specific character it
  newly admits. **The count is deliberately not quoted here.** An earlier draft
  said 26; the array holds 27, and the list is expected to grow as characters
  are added. The test is the source, and a number in prose that must be
  hand-synchronised with a list is a liability, not precision — which is the
  same lesson as the file-total above, applied before it cost a second
  correction. A well-formed but WRONG tag is accepted here and fails
  later at `npx`, where the error names the package — recorded as a limit with
  its own test, not left implied.
  **The deployed surface refuses rather than falls back.** The hosted MCP
  server is deployed per environment, not published, so it reads
  `HAVEN_CONNECTOR_CHANNEL` at module load with the SDK constant as fallback.
  Unset, empty or whitespace resolves to `alpha` — today's behaviour exactly,
  and the production blast radius, since production will not set it. A
  malformed value refuses the BOOT. That was decided deliberately: a silent
  fallback would put the production connector in front of a deployment that
  looked configured, which is the exact defect this epic exists to remove,
  reproduced one layer down.
