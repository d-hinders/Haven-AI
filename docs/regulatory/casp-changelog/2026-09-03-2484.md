# 2026-09-03 — #2484: Connect non-TTY approval-wait skip and enriched approve-budget CTA

Two prose-flow refinements in `packages/connect`, both about the budget-approval
moment, and neither touches the CASP perimeter: the approval stays a dashboard
action, the connector still only reads the read-only `connector-status` endpoint
with an agent-API-key auth (no new endpoint, no new authority granted), and no
signing, credential, or authority surface moves. (1) A prose run whose STDOUT is
not a TTY — an agent running the prose connect command as a tool call, where
there is no watching human — now skips the bounded `waitForBudgetApproval` wait
unless a library caller explicitly passes `waitForApproval: true`; the full
approve-whenever-ready handoff reaches the caller instead of being trapped
behind an opaque up-to-3-minute poll. Keyed on a new injectable `deps.isStdoutTty`
seam — the decision is about narration, so it keys on stdout, distinct from the
#1719 stdin prompt gate — while a real terminal still waits and `--json`
(`waitForApproval: false`) is byte-for-byte unchanged. (2) The approve-budget CTA
now carries the approval-relevant facts an agent relaying it verbatim needs:
budget amount, token, and reset period (human-formatted from `setup.agent_budget`
through the existing `formatAtomicAmount` / `describeResetPeriod` /
`resolveTokenFromAddress` helpers, with `describeApprovedBudget`'s tokenless
atomic-units fallback, multiple rows joined with commas) and the wallet label +
network. No secrets: only atomic amounts and the wallet label, both already
printed by `printSetupSummary`; nothing in the new text is a key, credential, or
address. The #2279 CTA gating (delivered-report liveness + handoff coherence) is
unchanged. Both behaviors are pinned by tests through the injectable seam, no
real timers. **Perimeter unchanged.**
