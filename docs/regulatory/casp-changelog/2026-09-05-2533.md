## What this change can and cannot do

- **It adds no capability.** No route, no schema, no signing path, no
  credential, no permission. Nothing executes differently.
- **It removes an `sk_live_` mock from a marketing page** and replaces it with
  the shape Haven actually mints (`sk_agent_`). This is a correctness
  improvement to a *displayed placeholder*, not a change to any credential:
  `/how-it-works` renders a static string in a visual, and the string was never
  a value. The 2026-09-04 cold-test report flagged it as vocabulary drift
  because an agent reading it would learn the wrong prefix.
- **The one-liner is untouched.** `npx -y @haven_ai/connect@<channel>` appears
  verbatim wherever it already did; the sweep renames the *concept*, never the
  command. The new README section deliberately prints no install or npx line at
  all — it links to the runbook — so the channel-neutrality #2515 established
  cannot regress through it.
