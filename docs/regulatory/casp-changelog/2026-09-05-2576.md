# 2026-09-05 — #2576: the connector-command vocabulary reaches the rest of its class

A **copy and documentation** change, classified **money-path by the file half**
on **one** glob of thirty-six changed files (35 modified + this shard):
`packages/backend/src/routes/agent-connection-setups.ts`
(`node scripts/ci/money-path-classify.mjs origin/dev`, self-test passed
6 positive / 6 negative). The issue's own checkbox says No;
the classifier says Yes, and the classifier is the authority.

**Zero behaviour changes, and the perimeter is unchanged.** No route, policy,
signing, custody, authority or spend surface moves. Outside comments and test
assertions, every edit in the diff is a string literal.

## What the money-path file actually changed

One line of `buildSetupPrompt`. The consent sentence

> I approve running this exact Haven **setup** command. It may …

becomes

> I approve running this exact Haven **connector** command. It may …

Three properties of that edit, each checked rather than assumed:

- **The consented ACTIONS are untouched.** They are built separately, as
  `approvedActions` — download and execute the named npm package, connect to
  the named API, write credential files under `~/.haven`, update the local
  agent MCP config — and interpolated by `joinApprovedActions`. The diff does
  not reach them. What the user approves is identical; only the noun naming the
  thing being approved changes, and the command itself is printed verbatim two
  lines below the sentence.
- **Nothing stored depends on the wording.** The prompt is generated per
  request. No migration and no repository names `setup_prompt`
  (`grep -rln setup_prompt packages/backend/src/db/migrations/` → no files;
  no INSERT/UPDATE path selects it), and it is not hashed or signed, so no
  consent record, replay check or verification reads this string.
- **It is the same one-word substitution as every other site in this sweep**,
  not a rewrite. No count is given here on purpose: the sweep's totals live in
  the Evidence section below, each beside the command that re-derives it, and a
  hand count restated here would have to define its own unit (occurrences? sites?
  files? do test-mirror assertions count?) and then stay in step with those
  totals. An earlier draft said "the other 53 sites" and did neither — it went
  stale when the measured total moved, and survived two rounds of otherwise
  careful figure-fixing because nothing could check it (haven-reviewer, this PR). The retired term is `setup command`; the canonical term, recorded in
  `docs/product/copy-guidelines.md` § *Agent-facing vocabulary* since #2533, is
  **connector command**.

It is included at all because the issue's own sweep command does not read
`packages/backend/src`, and this is the most-read instance of the retired term
in the product: it sits inside the setup prompt every user pastes to their
agent. Renaming the dashboard modal around it while leaving it is the drift the
issue exists to end.

## Product Copy Rules

§ *Product Copy Rules*' avoid list is unaffected — this change adds no
attribution claim and removes none. It does move one row of the vocabulary rule
from written-only to enforced: `setup command` and `connect command` are now
literals in `scripts/frontend-copy-lint.mjs`'s `BANNED`, a required check, on
the same footing as the two avoid-list phrases #2246 added. Measured before
adding: zero occurrences across the scanned set, so no baseline entry.

The guard's reach is narrower than the rule and is documented as such in both
the script and the copy guidelines, because a gate that reads as wider than it
is is the failure mode this document keeps recording. Proven by mutation, each
restored byte-identically:

| Mutation (retire one renamed site) | copy-lint |
|---|---|
| `components/connect-agent/setup-copy.ts` | **red** — `setup-copy.ts:84:128` |
| `packages/sdk/src/skill-content.ts` (SCAN_FILES, cross-package) | **red** — `skill-content.ts:196:3` |
| `packages/connect/src/installed-clients.ts` | green — outside SCAN_DIRS |
| `src/hooks/useAgentConnectionSetupStatus.ts` | green — `src/hooks` unscanned by design |
| `connect-agent/__tests__/runtime-status-copy.test.ts` | green — `walk()` skips `*.test.*` |

The last three are the documented gaps, shown failing to fire rather than
asserted. The connector's own strings, the backend and every test file were
swept by hand and nothing re-checks them.
