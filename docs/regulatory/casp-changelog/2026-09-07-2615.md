- **#2615** — observability on the mainnet RPC default; no authority, custody or
  route change. `packages/backend/src/config.ts` generalises #2511's Base
  Sepolia boot warning into a per-chain `warnPublicRpc` and wires `RPC_URL_BASE`
  through it, so an unset variable says so once at boot instead of silently
  substituting the shared public node. The CASP-relevant fact is what was
  measured, not what changed: production was resolving **Base mainnet** — the
  chain every real settlement, counterfactual account deploy and caveat-enforcer
  read goes through — to `https://mainnet.base.org`, a shared unauthenticated
  endpoint, with no signal of any kind. That is not a control failure (the
  caveat enforcers still enforce on-chain and Haven still cannot sign), but it
  is a monitoring gap on the money path: a degraded node surfaces as a paying
  user's failed payment rather than as a red workflow, because production has no
  money-flow harness pointed at it. This change adds the signal and nothing
  else. Two things it deliberately does NOT do, both recorded rather than
  decided in passing: it does not set the variable — that is an operator step,
  and this PR uses `Refs` so the issue outlives the merge — and it does not make
  a missing mainnet RPC fail-closed the way `DELEGATION_RAIL_BUNDLER_URL` is,
  which is an open OWNER decision (#2615 item 3) that the issue explicitly
  forbids taking inside the warning change. Mutation-proven rather than
  asserted, including one surviving mutation the first pass missed: reverting
  the call site to a bare `optionalEnv` was invisible to every function-level
  test until a module-load wiring test was added, which is the same shape as the
  defect itself. Perimeter unchanged.
