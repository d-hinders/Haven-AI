**What changed, as authority. Nothing.** The manifest's `environment` field is
a label the deployment reports about itself; nothing reads it to decide what
may be spent, signed or relayed. Production used to report `"unknown"` because
the build variable is unset there by convention (`dev-environment.md` § *The
`DEV` badge*) and the manifest read the raw variable; it now reports
`production`. An agent that reads the field learns which deployment it is
talking to — which is the fact the runbook's own funding step told it never to
assume and, until now, gave it nowhere to read.

**The runbook sentence, which is the CASP-relevant part.** Step 2 (funding, a
HUMAN step) gains: *"Before you write that message, read
`/.well-known/haven.json`: `environment` says whether this deployment is
`production`, and each `chains.supported` entry says whether that chain is a
`testnet`. Real money is at stake only on a non-testnet chain of a `production`
deployment — tell your user which case theirs is."* The first draft said
"`production` means real money on the chains it lists", which
haven-design-reviewer showed false: `chains.supported` is the registry's fixed
list and includes Base Sepolia on production too. The manifest's chain entries
therefore gain `testnet`, derived from the registry's faucet rule (#2534: a
faucet exists only on a testnet), and the sentence keys off that field. Read
against § *Product Copy Rules*:

- **Attribution.** The sentence names no actor that authorises anything. The
  human still funds the account, still signs the budget, and the agent still
  relays. Nothing added says Haven holds, grants, approves or moves funds.
- **Direction of the warning.** It makes the agent MORE explicit with its user
  about real money, not less: on production it must say so, on a test
  deployment it must say that instead. The failure it closes is the cold-agent
  run of 2026-09-08 inferring "production" from a Railway hostname — the exact
  inference the runbook forbids — because the manifest declined to say.
- **No new capability.** The agent reads a public JSON document it already
  read for the connector channel (#2617). It gains no credential, no key, no
  route.

**Custody.** Unchanged. No key material, credential or token is touched;
`api.ts`'s override gate keeps the #582 property (production never honours an
`?apiBaseUrl` override, so a crafted link cannot redirect a bearer token) — the
predicate moved into the helper and the three tests that pin it (production,
`prod`, unset) are unchanged and green.
