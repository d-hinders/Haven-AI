- **#2842** — a test-only change in the hosted MCP server with no source edit and no perimeter effect: `packages/mcp-server/src/tools-registry-boot.test.ts` moves its two module imports out of the test body and makes them static, so the cost of loading the SDK + server module graph is paid in vitest's collect phase rather than against a per-test timer. **Authority/custody argument: nothing under test changed and nothing in the product changed.** The file asserts one thing — that `buildHostedMcpServer` calls `assertHostedToolRegistry` before registering any tool, so a registry with a handler-less tool cannot boot — and that assertion is byte-identical before and after; the #2807 guard it protects is untouched, as is every handler, schema, refusal, cap check and signing boundary. The change is worth recording here only because of what the defect looked like: the test failed intermittently under a loaded full-suite run (4 red of 11 runs on clean `dev`) and the failure surfaced as the registry guard "not throwing", which reads like the completeness check regressing on a money-path package rather than like a timer expiring. A guard that reports a false regression is a guard that gets muted. **What is mutation-tested:** leaving the mocked handler map COMPLETE (not deleting `haven_pay`) turns it red, so the assertion is still live after the restructure; commenting out `assertHostedToolRegistry(handlers)` at its call site in `server.ts` turns it red, so the wiring this file exists to prove is still proven; and pointing the import at a missing module fails the file and exits 1 — verified on the exit code rather than on the reporter's word, which says "skipped". **What was measured rather than argued:** importing `server.js` costs ~1.2–3.4s depending on load and is 99.4% of the original test's duration, while the `vi.mock` factory contributes nothing detectable (2479ms from a file with no mock at all, against the same figure mocked) — so the first explanation shipped for this, blaming the mock factory, was wrong and is corrected in the file. An intermediate fix that hoisted the imports into `beforeAll` was rejected on measurement rather than taste: in paired full-suite runs under 28 spinning background processes it went red 1 of 2 with `Hook timed out in 10000ms` and the test listed as SKIPPED, where the static form was 2 of 2 green — the hook form trades the 5s test budget for the 10s hook budget instead of removing the exposure, and reports worse when it loses. Perimeter unchanged.
