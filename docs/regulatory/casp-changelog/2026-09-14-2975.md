  which the refusal fires (before any funding intent) are unchanged — no
  purchase that was refused is now allowed, and none that was allowed is now
  refused. Guidance fields only; no custody, signing, backend, or authority
  changes. Mutation-tested: dropping the guidance fields from the
  `PRICE_EXCEEDS_MAX` throw fails three tests (unit, catalog path, plain-HTTP
  path). Perimeter unchanged.
