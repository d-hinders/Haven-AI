- **#3318 (display follow-up to #3295/#3317)** — the published `@haven_ai/cli`
  renders the degraded-balance marker instead of presenting a stale figure or a
  filler zero as current: `wallets balances` (`packages/cli/src/commands.ts`)
  reads the additive optional `balanceFreshness` marker on
  `GET /balances/:accountAddress` entries and prints a stale entry as
  `≈ 25 ETH (as of 45m ago)` — the figure is real but was last read at `asOf` —
  and an `unavailable` entry as `unavailable` instead of the fabricated `'0'`.
  A clean entry (marker absent) is byte-identical to the pre-#3318 rendering,
  and `--json` is unchanged: the response passes through verbatim, marker where
  the server sent it, absent where it did not.

  Authority and custody argument: this is a rendering change in a read-only
  display command. No key material, signing, binding, verification, relaying,
  or payment execution moves; no new spender, approval, or credential surface
  is created; the CLI sends nothing new and calls no new route. The registry
  consumers — budget grant and `agents connect`, which read token address,
  decimals and symbol from the same response — neither read nor render the
  marker, and the additive optional constraint keeps those fields
  byte-identical whether or not an entry carries one. The stale hint moves the
  human display in the honest direction only: previously a failed read could
  render a figure the wallet's authority does not actually cover as if it were
  current (#2769's class); now the uncertainty is on the screen. No spend
  decision reads the rendered cell — budget magnitude comes from the
  human-entered `--amount` and the registry's decimals, unchanged.

  Tests: `packages/cli/src/commands.test.ts` pins all three renderings against
  fixture responses — clean byte-identical (prose and a no-synthesized-field
  census under `--json`), stale with the as-of hint (fake clock, 45m →
  `45m ago`) and the clean sibling untouched, `unavailable` replacing the
  filler zero — plus the marker passing through `--json` verbatim and budget
  grant building unchanged against a stale-marked registry. Perimeter unchanged.
