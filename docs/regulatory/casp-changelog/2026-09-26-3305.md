- **#3305** — **The release bump generates the public client release data
  from the package CHANGELOGs (epic #3302, slice 3). Release tooling and
  documentation only: no funds move, no signing path changes, no authority,
  custody or perimeter changes.** It is money-path by file, not by effect:
  `scripts/release-bump.mjs` is a control glob, and the signer's CHANGELOG sits
  under `packages/signer/**`. The signer change is one header paragraph, with
  no code.
  - **What the bump now writes.** On a real release `npm run release:bump`
    regenerates `packages/core/src/client-releases.data.ts`: the version
    released in source per published package and short notes for the newest
    releases, the data `/releases`, `GET /discovery` and
    `/.well-known/haven.json` serve (#3304). It is built from the CHANGELOG
    sections the bump has just stamped.
  - **What it refuses.** Before writing anything, the bump regenerates the file
    from the CHANGELOGs as they stand and refuses to run if the file on disk
    differs. CI runs the same comparison on every pull request, so a hand edit
    goes red there first.
  - **The marker.** `**Update required**` anywhere in a release's CHANGELOG
    section (outside a code span) sets that release's `action_required`, and
    a top-level bullet carrying it leads
    its note. `**BREAKING**` does not.
  - **What it never writes.** `client-compat.ts`, the table of enforced
    minimums, is never written by the bump, and a test fails if the bump's code
    names it. A release therefore cannot raise a minimum, and so cannot start
    refusing clients, as a side effect. That decision stays a hand-edited owner
    decision.
  - **Snapshots.** A `--snapshot` run skips both the refusal and the write,
    exactly as it skips the CHANGELOG heading.
  - **Tests.** The existing CHANGELOG-heading and snapshot tests pass unchanged.
    Each new guard has a mutation that turns its test red: marker detection,
    the hand-edit check, the snapshot skip, and refusal-before-write.
  - **Perimeter.** Everything the file serves was already public in the
    CHANGELOGs. No route, credential scope, key handling or spend path is added
    or widened. Custody unchanged. Perimeter unchanged.
