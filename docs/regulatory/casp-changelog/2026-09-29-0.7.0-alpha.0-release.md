  **What the release carries, by effect on authority:**
  - **#3330 (#3444), sub-agent budgets. This is the widening.** An agent's delegate account can grant another agent in the same account a narrower slice of its own budget, owner-co-signed. The sub-agent redeems a three-link `[grant, parent-child, budget]` chain, or four links under an erc7710 settlement child. Every hop's caveats run in one redemption, so the parent budget delegation still bounds the spend on-chain. The backend refuses a child wider than its parent before signing. The signer checks the payload against the sign context (an authenticated fetch) before signing. It has its own shard.
  - **#3419 (#3454), narrowing.** The signer refuses undeclared top-level arguments. Task-budget handoffs carry the old-signer recovery notice.
  - **#3412 (#3415).** Upgrade hints name the connector doctor, and `--repair` refuses to act on a machine with several agents unless `--credentials-dir` names one. A repair can no longer re-pin a different agent's signer. This is the connector half of epic #3302.
  - **#3417 (#3445), #3418 (#3448), #3420 (#3453).** Settled-replay reporting, a `verify_receipt` that never throws and verifies the delegation digest, and a terminal status for a delivered-but-unsettled erc7710 payment. These are reporting correctness only.
  - **#3410 (#3443).** The local consent screen renders the budget in whole tokens. The consent hash is untouched.
  - **#3411 (#3447), #3418 (#3448), #3417 (#3445).** The breaks above. Each is input refusal or error typing only, with no authority change.
  - **#3332 (#3400).** An additive `PaymentParties.buyer` in the SDK.
  - **#3392 (#3406).** The SDK refuses an idempotency key replayed under a different task budget (`X402TaskBudgetMismatchError`) before any network call. This is a narrowing.
