  - **Live-delegation signal:** `GET /agents` and `GET /agents/:id` return `live_delegation_count`, the agent's `agent_delegations` rows in `pending`, `active` or `replaced`. One shared status set (`LIVE_DELEGATION_STATUSES_SQL`, `infra/repositories/delegation-budgets.ts`) now defines "live" for that count, for the `revoke-all` target list, for the archive guard (`ARCHIVE_AGENT_SQL`, `AGENT_HAS_LIVE_DELEGATIONS_SQL`) and for the account-delete guard (`HAS_LIVE_DELEGATIONS_FOR_ACCOUNT_SQL`). The two guards previously checked `pending`/`active` only.
  - **Dashboard revoke paths:** the post-connect replaced-agents card revokes the credential, then asks for one passkey signature to end the budgets (`SupersededAgentsCard`); the Remove dialog decides whether a signature is needed from the agent's loaded delegation list, not from `agents.status` (`RemoveAgentDialog`).
  - **Half-revoked visibility:** an agent that is revoked or archived while `live_delegation_count > 0` is marked on the agents list, the Removed group's toggle, the agent page and the account page, with a **Finish revoking** action where Haven can end it.

  Authority and custody argument: authority only narrows; nothing is granted.
  - **Who ends a budget is unchanged:** only the owner, by passkey or owner-wallet signature over `disableDelegation`, through the existing `revoke-all` routes. Haven still signs nothing and cannot end a budget itself.
  - **The guards tighten.** A `replaced` row stays enabled on-chain until the owner's Stop userOp lands, so the delegate key can still redeem it. Counting it as live means an agent holding only such a row can no longer be archived into the Removed group, nor orphaned by deleting its account from Haven. `revoke-all` already moves `replaced` to `revoked` before archive runs, so Remove still completes.
  - **Invariant (owner-confirmed threat model, 2026-10-01):** no dashboard surface tells the owner an agent's spending has ended while any of its delegations is not confirmed dead. Every dashboard revoke either ends the budgets or leaves the agent visibly half-revoked with a one-click finish.

The dashboard's unlinked-agent handling (marker without an action, no signature gate) is defensive and unreachable today.
