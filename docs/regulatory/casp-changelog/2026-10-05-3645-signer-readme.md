  bound (`SIGN_CONTEXT_TIMEOUT_MS`) applies to all four reads.

  local-to-hosted guide follow in the same PR.

what it was: authenticated reads of a signing context, never a write, never the
delegate key or a signature. The README now describes all of it instead of the
payment half. Haven holds no key, signs nothing and moves no funds.
