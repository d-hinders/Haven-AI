- **#4217**: test-only. It changes the messages of the Red Line #4 on-chain
  enforcer probe, and the backend suite now runs under a network net. There
  is no perimeter change.
  `packages/backend/src/rails/__tests__/helpers/enforcer-probe.ts` is the
  covered file, and three of its messages printed the full probe RPC URL:
  `unreachableMessage()` and both `EnforcerProbeTransportError` texts
  (fetch threw; HTTP error status). `HAVEN_ENFORCER_PROBE_RPC_URL` is the
  paid endpoint in CI, and its key rides in the userinfo, path or query.
  The contract test throws `unreachableMessage()` from its `beforeAll`, so
  a failing job would have published the key in a public CI log. A new
  `probeEndpointLabel()` prints `URL.host` (the host, plus the port only
  when it is not the default) in all three. Four cases drive
  `https://user:pass@rpc.example/v2/SECRETKEY?apikey=X` through the label,
  the message and both transport errors. They assert that no credential,
  path or query fragment appears. Reverting each site to the full URL
  reddens its own case, and widening the label to `href` or `host + pathname`
  reddens four. The fetch-failure error no longer carries undici's raw
  `cause`, whose message can quote the credentialed URL and which vitest
  prints. It now carries `transportCauseSummary()`: each error's name and
  code down the chain, with no message text. One case drives a `TypeError`
  quoting the URL over an `ENOTFOUND` cause through it and checks the
  `util.inspect` output. Restoring the raw cause, or keeping the message in
  the summary, reddens it.

  What the probe decides is untouched: `decideProbeMode`, `probeReachable`,
  `probeEnforcer`, `assertTestnetOnly` and the revert decoding. The
  existing 27 cases stay green. The same PR adds the backend test network
  net (`src/infra/__tests__/helpers/test-network-net.ts`). It refuses every
  non-loopback connection a test makes, and its one exemption is
  `non-custody-onchain-enforcer.contract.test.ts`, scoped to the host
  `resolveProbeRpcUrl()` returns. So this proof still reaches Base Sepolia:
  its 6 cases ran green under the net. With `CI=1` and an unreachable RPC
  it still fails the file on the CI-fail branch rather than skipping, and
  the message names only the host. Every other host is refused inside that
  file too.

  No production code, custody, signing, settlement, funding or refusal
  decision changes, and `globs` and `controlGlobs` are not touched.
  Perimeter unchanged.
