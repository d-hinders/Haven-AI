- **#4351 — budget end dates 2/4: `expires_at` capped at 365 days on the
  delegation build route, schema and CLI** — authority-narrowing only; no new
  custody, key or route surface.
  - **What changed:** `POST /agents/:id/delegations/build`
    (`packages/backend/src/routes/agent-delegations.ts`) now refuses an
    `expires_at` more than 365 days out (400, same `{ error }` envelope as the
    existing future check), closing the "No expiry" permission listed in
    `docs/regulatory/casp-risk-guardrails.md`. The request schema
    (`packages/backend/src/openapi/spec.ts`, mirrored into
    `packages/core/src/api-types.ts` via the generator) documents the cap, and
    the CLI's `--expires` parse refuses past-cap values with the same bound
    (`packages/cli/src/args.ts`, README updated). A build exactly at the cap
    is still accepted, and the default (now + 90 days) is unchanged.
  - **The cap is deliberately OFF the re-key path:** rotation carries the old
    row's `expires_at` through the meter snapshot and `planCarry`
    (`routes/agent-rekey.ts` → `modules/agents/rekey-carry.ts`) and never
    passes through the build route, so a legacy row past the cap stays
    rotatable — rotation is the response to a suspected key exposure and must
    not refuse on the cap. The bound lives in the build route, never in a
    shared policy builder; pinned by a real-Postgres issue test
    (`agent-rekey-issue-past-cap.test.ts`) and a `planCarry` unit pin that
    guard against a later "centralise the validation" refactor.
  - **Perimeter:** the agent's on-chain authority can only shrink — an
    expiry cap removes a way to mint effectively unending budgets; nothing
    signs, funds, settles or moves keys differently, and the enforcer still
    holds whatever window the signed delegation says. Mutation-proven: with
    the bound dropped, the past-cap and past-cap-with-`replaces` tests go red;
    at the cap the build is accepted. Census first (recorded on the issue):
    0 live rows past the cap in the reachable dev database, so no existing
    authority is affected. Perimeter unchanged.
