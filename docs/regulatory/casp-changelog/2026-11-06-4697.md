- **#4697** — the hosted MCP's refusal for an agent API key Haven does not
  accept (`AGENT_IDENTITY_UNVERIFIED`) now names the account owner and an
  action that exists for a revoked agent. Slice of epic #4674; the wording was
  approved by the owner on the issue (2026-11-06).
  What changed, all in
  `packages/mcp-server/src/tools/identity-gate.ts`:
  - The `message` keeps the first sentence and the Bearer-key check, and
    replaces "or reconnect the agent in Haven" with: if the key is correct,
    the account owner can check this agent in Haven and connect a new one if it
    no longer has access. Nothing re-activates a revoked agent, so
    "reconnect" was a step that could not succeed.
  - The `next_tool_omitted_reason` no longer says "before any tool can run"
    (`haven_verify_receipt` and `haven_sweep_delegate` are exempt from the
    gate); it says no payment tool can run and names the same two steps.
  - Both strings are exported constants, so the next-step fixture and the
    tests use them rather than a copy.

  Why the perimeter is unaffected. Only the text of an existing refusal
  changes. The 401 condition, the code `AGENT_IDENTITY_UNVERIFIED`,
  `next_action: stop_and_tell_user`, the absent `next_tool`, and the exempt
  set `IDENTITY_GATE_EXEMPT` are unchanged, and the gate still does not relay
  the backend's 401 body, so a mistyped, archived or revoked key still gets one
  answer that does not say which it was. Nothing is signed, built, moved or
  retried; the hosted server stays keyless; no key, delegation, caveat,
  budget, route, wire field, client, env or on-chain surface moves.

  Tests: `packages/mcp-server/src/strict-tool-input.test.ts` pins the full
  message and omitted reason with `toBe` through the real
  `requireAgentIdentity`, drives a gated tool with the backend's two different
  agent-key 401 bodies (`AGENT_MISSING_KEY_BODY`, `AGENT_INVALID_KEY_BODY`,
  hints included) and asserts byte-identical answers that contain neither
  body, and retargets the paused-agent must-stay-absent assertion to the
  exported constants. Mutation cells in the PR body.

  Perimeter unchanged.
