- **#5089** — Haven's hosted MCP buyer (and the SDK's `quoteMcpX402` /
  `completeX402MerchantCall`) can pay a **stateless** MCP server: one that
  answers `initialize` with a valid JSON-RPC result and no `Mcp-Session-Id`.
  Owner decision of 2026-11-25 on #5086, option (a).
  - **What changes:** which merchants the hosted buyer will pay, and the
    headers on the requests it sends them. Before, such a server was refused
    at the quote, before anything was created. Now it is quoted, and the
    unpaid probe and the paid retry carry `Accept: application/json,
    text/event-stream` (a strict server answers 406 without it, which on the
    paid retry would be after funding).
  - **What does not change:** a 200 that is not an `initialize` result, a
    JSON-RPC error and a failed call are still refused before any payment,
    with the same message; a plain-HTTP request gains no header; the local SDK
    `fetch()` keeps paying a stateless server as standard x402; amounts,
    recipients, budgets, the signer, custody and authority are untouched; the
    payment is still delivered only to the endpoint Haven stored (#5086).
    No backend change, no migration.

  Perimeter unchanged.
