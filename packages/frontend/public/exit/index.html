Your exit path

Discover and inspect your agent budgets on-chain, and get everything you need to revoke them — no Haven account, no Haven server.

DelegationManager:
Revoke a specific delegation

Paste a delegation object Haven gave you (or one found above). Revoking it is an operation your ACCOUNT signs (a UserOp calling disableDelegation) — the docs show the exact steps, or your account's own signers can always rotate keys / move funds as the universal backstop.

A delegation that was issued but never used is an off-chain object no one can discover until first use — that is by design. Your revocation guarantee does not depend on finding it: you can revoke any delegation you can reconstruct (paste it above), and your account's own signers can always rotate keys or move funds. The step-by-step manual path (Etherscan + the contract ABI) is in Haven's public docs and works without this page.
